Cookie Consent — Demo & Integration

The mx_consent banner

A drop-in consent banner that writes the mx_consent cookie described in the Cookie Policy, gates non-essential scripts until consent, and respects Global Privacy Control / Do Not Track.

02 Add it to a page

<!-- 1. include once, ideally before other scripts -->
<script src="cookie-consent.js" defer></script>

<!-- 2. gate any non-essential script: it runs only after consent -->
<script type="text/plain" data-consent="analytics"
        src="https://your-analytics/snippet.js"></script>

<!-- inline works too -->
<script type="text/plain" data-consent="analytics">
  initAnalytics(); // only fires if analytics consent granted
</script>

<!-- 3. a re-open trigger anywhere (footer link, settings menu) -->
<a href="#" data-cookie-settings>Cookie settings</a>

03 Use the API in your app

// React / Vue / vanilla — same global object
if (MatrixConsent.allowed('analytics')) {
  startTelemetry();
}

// react to changes (banner choice, preference edits)
MatrixConsent.onChange(function (consent) {
  console.log(consent); // { necessary, functional, analytics, ts, v }
  if (consent.analytics) startTelemetry(); else stopTelemetry();
});
Notes for production The cookie is SameSite=Lax, Secure on HTTPS, Path=/, 12-month max-age. Bump VERSION in cookie-consent.js after any material cookie-policy change to re-prompt all users. For EU/UK users this gives a genuine prior-consent gate (non-essential scripts don’t run until accepted). Wire your real analytics tag into the data-consent="analytics" slot and remove the placeholder URLs.
