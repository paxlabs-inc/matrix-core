## Centra AI とは？

Centra AI は、Sidiora Labs が開発する、プライベートかつ永続的なエージェントプラットフォームです。ソフトウェア開発、複雑な調査、ブラウザーやファイルの操作、複数の専門エージェントによる並列作業、成果物の生成など、1 回のプロンプトでは確実に完了できない仕事を想定しています。セッションをまたいでも作業状態を失わず、そのまま継続できます。

システムの中核を担うのは 2 つのエージェントです。

- **Neo** は主要エージェントです。調査と推論を行い、ツールを操作し、成果物を作成し、進行中の作業を管理します。1 回のモデル応答で終わらず、完了までタスクに取り組み続けます。
- **Ion** は技術エージェント兼コーディング環境です。制限されたワークスペース内で、実際のプロジェクト、シェル、ファイル、テスト、プレビュー、開発ツールチェーンを直接扱います。

これらを支える **Workforce** は、大きな目標を管理された並列作業へ分解する協調実行レイヤーです。**Neo Computer** は、情報源、プレビュー、成果物、変更履歴、ワークスペース上の証拠を一元的に扱う場所です。

会話は操作面であり、その背後で動く作業システムこそが Centra AI の本体です。

## Centra AI の特徴

- **永続的な認知。** ID、記憶、目標、証拠、未完了の作業は、プロセスの再起動やコンテキストウィンドウの切り替えを越えて維持されます。
- **実在する実行環境。** エージェントは、リポジトリ、ターミナル、ブラウザー、サービス、データベース、メディアツール、外部システムを直接操作します。
- **見栄えではなく証拠。** 情報源、引用、ツール結果、成果物、チェックポイント、検証結果は、その作業との関連を保ったまま記録されます。
- **長期的な作業。** タスクは分解、キューイング、修正、再開、継続が可能で、権限を限定した専門エージェントと協調できます。
- **人間による制御。** 機密性の高い操作や外部への影響を伴う操作には、明示的な権限境界と承認手順が適用されます。
- **ユーザーごとの隔離。** 各ユーザーに専用のエージェント環境と永続的な状態境界が用意されます。

## 主な機能

| 領域 | Centra AI が提供するもの |
| --- | --- |
| ソフトウェア開発 | リポジトリを理解したコーディング、シェル、パッケージ、テスト、サービス、差分、プレビュー、プロジェクト納品。 |
| 調査 | 複数情報源の調査、正確な引用、原文抜粋、統合分析、永続的な調査成果物。 |
| コンピューター操作 | 可視化された証拠と制限された権限を伴うブラウザーおよびデスクトップ操作。 |
| 記憶 | ID、設定、事実、目標、会話の継続性、証拠に結び付いた判断。 |
| 協調作業 | タスク分解、専門エージェント、制限された並列実行、監督、再開可能な作業。 |
| 自動化 | スケジュール実行、オンデマンド実行、永続キュー、プロアクティブな成果物配信。 |

## クイックスタート

```bash
git clone https://github.com/Sidiora-Labs/centra-llm-agents.git
cd centra-llm-agents
make build
make install
```

クライアント:

```bash
cd client
corepack enable
pnpm install
pnpm dev
```
