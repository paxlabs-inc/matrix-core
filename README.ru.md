<h2 align="center">Фреймворк агентов и слой когнитивных возможностей для LLM.</h2>

<p align="center">
  Matrix выводит LLM за пределы чата и переводит его к исполнению действий во всей цифровой среде <br/>
  позволяя людям и машинам координироваться в работе, где требуется абсолютная точность.
</p>

## Что такое Matrix?

Matrix — это слой когнитивных возможностей, созданный для концепции Machine Economy в Paxeer Network. Он расширяет языковую модель за пределы диалога и переводит её к реальному исполнению: финансовой координации между агентами в блокчейне, выполнению задач с высоким уровнем риска и безопасной работе с критически важной и конфиденциальной информацией.

Большинство агентных стеков ломаются на задачах такого класса потому, что протаскивают естественный язык до самого нижнего уровня. Человеческий язык — это канал с утечками: биологический способ, которым мы рассуждаем, воспринимаем и приближённо оцениваем, проникает в каждое создаваемое нами предложение. Для чата это допустимо. Но это недопустимо, когда агент перемещает средства, выполняет необратимую запись или работает с конфиденциальными данными. Matrix даёт людям и машинам способ координироваться именно в такой работе, *не позволяя* неоднозначности человеческого мышления и языка проникать в те части системы, где неоднозначности быть не должно.

Для этого используются три слоя.

## Три слоя

### 1 — The Matrix Compiler (MCL)

**Верхний уровень управления всего стека.** MCL — это группа из трёх строгих агентов, которые общаются, планируют и действуют между собой через протокол закрытых глаголов, свободный от ограничений и неоднозначности человеческого языка и человеческого ввода. Они координируются с машинной точностью и применяют её к реальным высокорисковым и чувствительным задачам: деньгам, необратимым операциям и работе с конфиденциальной информацией.

Когда задача переходит границу и становится действительно значимой по последствиям, она попадает сюда. Три агента вычисляют пространство возможных исходов, подтверждают, что располагают всеми входными данными, необходимыми для работы, запрашивают уточнение, если чего-то не хватает, и затем выполняют задачу один раз — строго по спецификации. Ничего не запускается на основе догадки.

### 2 — The Cortex

**Полноценный движок памяти, контекста и неизменяемого состояния.** Cortex даёт каждому агенту постоянную и долговечную память: временную шкалу событий для каждого участника, активное внимание и типизированное состояние, которое только дополняется и может быть детерминированно воспроизведено на уровне байтов. Непрерывность перестаёт быть иллюзией, которую модель должна имитировать в каждой сессии: для пользователя она реальна, а для агента — неразрушима. Агент, работающий на Matrix, не просыпается пустым.

### 3 — The Loop Manager

**Цикловый движок для каждого агента.** Для каждого агента Loop Manager координирует постоянный поток и обмен между пользователем, LLM и Cortex и передаёт задачу в конвейер MCL в тот момент, когда работа становится значимой по последствиям. Это среда выполнения, которая сохраняет целостность агента между диалоговыми ходами, инструментами и временем и точно знает, когда решение нужно передать выше, а не продолжать импровизировать.

## Как всё это работает вместе

```
                        +-----------------------------+
                        |            User             |
                        +--------------+--------------+
                                       |
                                       v
                    +------------------+------------------+
                    |           Loop Manager              |
                    |     per-agent coordination loop     |
                    |     user  <->  LLM  <->  Cortex     |
                    +----+---------------+-----------+----+
                         |               |           |
                 reversible work         |       escalation
                         |               |           |
                         v               v           v
                    +---------+    +-----------+  +------------------+
                    |   LLM   |    |  Cortex   |  |  Matrix Compiler |
                    | (chat,  |    |  memory   |  |  (MCL)           |
                    |  tools) |    |  context  |  |  3 rigorous      |
                    +---------+    |  immutable|  |  closed-verb     |
                                   +-----------+  |  agents          |
                                                  +------------------+
                                                    money / on-chain /
                                                    irreversible /
                                                    confidential
```

Стандартный разговорный агент (**Neo**) работает внутри Loop Manager и при выполнении обратимых задач имеет доступ к shell, code, fetch и web-инструментам. Как только уровень риска повышается, Loop Manager передаёт задачу в MCL, а управление возвращается к Neo, когда повышенная строгость больше не требуется.

## Модули

Корневой Makefile управляет набором соседних Go-модулей — каждый из них имеет собственный `go.mod` и может независимо выполнять `go build` / `go test`. Три описанных выше слоя отображаются на них следующим образом: **MCL** — это группа компиляторных агентов, **cortex** — движок памяти, а **executor** реализует Loop Manager.

|--------|------|
| **MCL** | Группа Matrix Compiler. Три строгих агента с закрытыми глаголами, которые с машинной точностью планируют и выполняют высокорисковые и чувствительные задачи. |
| **cortex** | Типизированный движок памяти для каждого участника на базе Pebble. Журнал только для добавления, снимки с привязкой к Merkle, детерминированное воспроизведение на уровне байтов. Постоянный, неизменяемый, долговечный. |

| **layerx** | Расчётная инфраструктура и кастодиальный каркас для балансов агентов. |
| **chronos** | Централизованный планировщик агентов и система пробуждения. |
| **atlas** | Дополнительный слой оркестрации инфраструктуры. |
| **context** | Подсистема управления контекстом. |

## Ключевые архитектурные решения

- **Координация через закрытые глаголы (D7)**: агенты MCL координируются с помощью 10 закрытых глаголов — `find`, `acquire`, `build`, `modify`, `deliver`, `analyze`, `negotiate`, `schedule`, `monitor`, `delegate` — поэтому намерение между агентами является точным и никогда не выводится во время выполнения из свободного текста.

- **8 закрытых типов объектов**: `service`, `model`, `agent`, `knowledge`, `intent`, `asset`, `plan`, `capability`. Каждый операнд относится к одному из этих типов. Неструктурированные блоки данных не могут перейти границу и попасть в исполнение с существенными последствиями.

- **Инвариант воспроизведения (раздел 13.4)**: производное состояние всегда можно восстановить из журнала с побайтовой идентичностью. Это проверяется для каждого pull request через `make ci`. Ни одно действие агента не остаётся без учёта, и ничто из того, чего он не делал, не скрывается.

- **Неизменяемая память**: Cortex работает только на добавление и использует адресацию по содержимому, поэтому непрерывность агента нельзя незаметно переписать — долговечно для агента, надёжно для пользователя.

- **Подписанные квитанции**: каждый запуск со значимыми последствиями завершается квитанцией EIP-712 — входы, выходы, стоимость, хэш — которую любой может проверить постфактум.

## Быстрый старт

### Требования

- Go 1.22+
- GNU Make 4.x
- Node.js 20+
- Python 3.11+
- Docker с Buildx

### Сборка

```bash
# Clone the repository
git clone https://github.com/paxlabs-inc/matrix-core.git
cd matrix-core

# Build all nine Go modules
make build

# Install runnable CLIs into ./bin
make install

# Run tests (go test -count=1 -race ./... per module)
make test

# Full CI check (gofmt + vet + tests; mirrors GitHub Actions)
make ci
```

### Настройка

```bash
# Copy the example environment file
cp .env.example .env

# Required for consequential (non-dry-run) execution:
#   FIREWORKS_API_KEY
#   TOGETHER_API_KEY
#
# Required for authenticated daemon mode:
#   MATRIX_DAEMON_TOKEN
```

### Запуск цикла агента

```bash
./bin/mcl-execute walk \
  -prose "Summarise the README and write it to /tmp/summary.md" \
  -manifest    agents/default.json \
  -cortex-root ./runs/dev-cortex \
  -skills-root ./skills
```

### Запуск Daemon

```bash
./bin/mcl-execute daemon \
  -addr        :8080 \
  -cortex-root ./runs/dev-cortex \
  -manifest    agents/default.json \
  -skills-root ./skills
```

## Справочник API

Daemon предоставляет лёгкий HTTP API для взаимодействия с агентами.

| Метод | Путь | Назначение |
|--------|------|---------|
| `GET` | `/healthz` | Проверка работоспособности + статистика SSE broker |
| `POST` | `/chat` | Диалог с агентом (разговорный цикл через Neo) |
| `GET` | `/events` | Поток Server-Sent Events для отслеживания транскрипта в реальном времени |
| `POST` | `/messages` | Отправка сообщения со значимыми последствиями (эскалация к группе MCL) |
| `GET` | `/intents/{id}` | Чтение цепочки intent envelope по intent ID |
| `GET` | `/me` | Пользовательские настройки и идентичность |
| `POST` | `/shutdown` | Корректное завершение обработки и остановка |

## Участие в разработке

Matrix Core является проектом с открытым исходным кодом, и вы можете свободно **форкать и изменять его**. Однако ветка `main` разрабатывается исключительно основной командой: незапрошенные pull request, как правило, не объединяются, а внешние изменения принимаются только после прямой совместной работы с автором изменения.

Перед тем как что-либо открывать, прочитайте политику участия в начале [Руководства для участников](CONTRIBUTING.md). Issues, отчёты об ошибках и сообщения об уязвимостях всегда приветствуются.
